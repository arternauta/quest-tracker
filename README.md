# Quest Tracker ⚔️

A pixel art JRPG-style project dashboard inspired by The Legend of Zelda NES.

Track your projects as quests with hearts, XP, rupees and the Triforce.

## Run

```bash
python3 -m http.server 3333
```

Then open `http://localhost:3333`.

## Data

Edit `data/quests.json` to add or update quests.
